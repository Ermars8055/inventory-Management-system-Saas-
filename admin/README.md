# StockPilot Admin

Admin panel for the StockPilot inventory management SaaS platform.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Docker

Built as part of the main `docker-compose.yml` in the project root:

```bash
docker compose up --build
```

The admin panel runs on port **8061** by default.
